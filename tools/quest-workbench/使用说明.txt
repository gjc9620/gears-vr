GearsVR Quest 武器工作台 0.5.3-dev（build17）

这是独立的 Q3 应用，不需要开游戏。电脑入口：Quest Workbench.exe。

最快开始
1. 武器库选择武器。进入该武器后，上方只列可以实际交互的部位。
2. 选择部件，立即在原枪位置预览它当前保存的左右手姿势。
   点“子弹”（左轮为“装填弹巢”）会隐藏枪体，只显示本枪实际装填用弹药；盒匣枪显示弹匣，其他显示散弹、实弹、箭或装填组件。
   可独立采集它的左右手姿势，切回握把/机构后恢复枪体。
   弹药不顺手时，点“移到操作手前”，或把手柄靠近弹药按侧握键拿起，移动、旋转后松开固定。
   点“恢复摆放”可回到原位置；再放下采集手的手柄，用另一手点击采集。移动中不能采集。
   弹药独立摆放只用于编辑；切回枪体/进入测试恢复原枪位置，已采姿势仍按物体局部坐标使用。
3. 采集时放下需要采集那只手的手柄；另一只手点击“采集左手”或“采集右手”。
   首次使用先展开裸手，在高级设置里分别校准。每次采集自动新增独立条目。
4. 点大号“测试手感”，用右手侧握拿枪、右扳机射击、左手操作机构。
5. 按 A/X 返回编辑，调好后再进测试；同一应用进程中保留各武器的弹量与机构状态。
6. 右上“保存”保存项目。电脑管理器“导出姿势和测试设置”备份整个姿势库。

黄色步骤引导
默认开启，只突出当前下一步需要操作的区域，并显示简短提示。
例如：打开机构 → 左肩弹药补给 → 装填口 → 闭锁；完成后黄框自动切换。
握持点也有引导；霰弹枪显示右手下压/抬回方向。高级设置可关闭，并随项目保存。
黄框是操作提示，不代替真实抓取、接近、插入和扳机/Grip动作。

各武器操作
• Lancer：左手拔匣，松手旧匣消失；左肩取新匣、插入。空仓需拉栓并回位。
  电锯手进入区域展开，离开收起；推到底启动，原有回拉/释放复位流程保留。
• Hammerburst 兽族步枪：开弹匣锁扣 → 拔匣 → 左肩取匣 → 插入 → 关锁扣。
  无论换弹前有无子弹，均不增加拉栓步骤。
• Snub：拔匣、左肩取匣、插入；空仓还需拉套筒到底并松手回位，半仓无需拉套。
• “护木支撑”保留为独立的“副手握持（Second Hand）”，代表第二只手的抓握位置，不限于护木。
  左轮/Snub的副手可在握把附近，各步枪按实际支撑位置采集。独立保存副手区域、手腕与指节，
  不再把副手姿势合并进主握把左手。左轮/Snub仍不通过两手短距离连线改变枪口方向。
• Boltok 左轮：左手抓转轮区域向左拉出；松手到左肩取整只装填弹巢；对准开放
  弹巢插入；再把左手掌靠近弹巢，重新按一下 Grip 合上。不需要第二段推回行程。装填物是整只六孔弹巢，不使用单颗子弹或快速装弹器，也不开放其他装饰件交互。
  一次补 min(容量−当前弹量,备用)；容量6、备用参考上限24，不丢掉原有实弹。
• Gnasher：左肩逐发取弹送入装填口，每轮最多补3发。左手抓住护木固定枪，右手
  大幅向下压，再抬回完成上弹。换弹末尾与每次射击后都要完成。不做装饰转枪。
• Longshot：提起栓柄 → 后拉到底 → 左肩取一发 → 送入膛口 → 向前推 → 转下锁定。
• Boomshot：拉开装填机构 → 左肩取原装填组件 → 送入 → 关闭机构 → 射击。
• 扭力弓：左肩取箭 → 送入装填位置；右扳机按住蓄力，松开射出。
• 黎明之锤：握持，按住右扳机测试光束指向。没有虚构弹匣换弹。
• Troika：双手分别握住两侧握柄，右扳机射击。弹量和自动补给是工作台预览参数。
• 破片/烟雾手雷：真实松开右手 Grip 投出，可观察轨迹；失追不会当成主动投掷。

编辑与预览
主面板保留两只手的采集按钮和测试按钮。点击上方部件可查看保存姿势。
高级设置收起 Volume、Snap、手腕/指节、反馈和左肩区域调整。旋转控件只在选中部件
并展开相应设置后显示；区域按部件使用不同颜色。只保留交互部件入口，原模型完整保留。
部件面板默认固定在侧边60cm处，高级设置可调45~120cm。
切换武器保持工作区朝向与主握点位置；不会自动回中。需要移动工作区时按 B/Y。
姿势库可查看各次采集、另存修改；真实采集优先于可编辑的默认模板。
控制器显示的闭合手模不是裸手原始采集，不能拿它伪造手指追踪数据。

保存与安装
每次采集独立保存在 captures/，项目按武器保存，已有文件不主动删除。
右上保存包含手腕、手指、Volume、Snap、左肩区域、反馈参数和黄框开关。
电脑管理器检查连接 → 安装/更新 → 在Q3打开。覆盖安装保留应用数据。
导出完整项目供后续 Mod 接入；旧 Mod 编辑器手指转换仍只支持 Lancer。
自定义 GLB 的任意骨骼和机械逻辑不会因导入自动配置，本版完整交互目录限内置武器。

与游戏的关系
Lancer沿用已冻结的便携 Mod 规则；新增武器采用工作台专用模拟，霰弹枪杠杆复用冻结
的共享规则。它们不是原游戏的动画、库存回执、弹道、敌人或运行对象。
默认抓点/手型及新增机械行程仍需要你在头显调校。枪和原交互部件来自原资源；弹药
使用已有模型，弓箭为明确标记的制作预览件。材质为工作台灰模。
射速、后坐力、声音、光束、投掷物和机枪补给是预览，不能认定与游戏手感完全一致。
满意后仍要把配置接入 Mod，再在游戏中对照。工作台不会自动覆盖游戏。
此版已进行编译及本地流程检查；安装、头显显示和实际手感单独记录。
