# 相机切换观测与菜单恢复

2026-10-15。继续采用冻结 GameRecovery8 / SpaceRecovery3，遵循游戏分辨率；没有增加渲染 Hook，也没有启用 DLSS/DLAA。

## UI 最后输入玩家不等于本地玩家身份

实际 PID33072 的一致复读显示：`PenderCrossplayInvitePopUp / WarUIScene_CrossplayInvitePopUp / input_mode=2`，阻塞计数0，但 `player_index=-1`。`MenuReader` 返回的字段来自顶层 `UIScene.LastPlayerIndex`，不是 `LocalPlayer` 或 Controller 的编号。旧显示分类器统一要求0，会把这个已观察到的游戏状态误分为 UNKNOWN；死亡菜单之后，这可能阻止恢复候选出现。

现在仅对上述精确匹配的非模态场景接受整数 -1 或0。死亡菜单仍要求0；其他负值、其他玩家、缺失值、类型错误、阻塞、场景或复读不符均拒绝。GAMEPLAY 只是显示恢复候选，实际双目仍需要身份正确、恢复时间边界之后的新渲染票据；没有把 UI 状态当成相机或 GPU 证据。

9项 Python 分类/发布测试通过；现有 StartupPanelPolicyTest 通过，保留死亡→UNKNOWN→游戏候选过程中旧票据不能解除恢复边界的条件。未在这一轮人为制造死亡，故不声称已经实际覆盖死亡恢复。

## 只读相机路线采样

新增 `tools/game-io/camera_phase.py`：按进程 PID＋创建时间绑定，沿当前反射字段读取受控 Pawn、ViewTarget、CameraStyle 和相机时间戳。核验角色身份、相互关系、注册表与名字槽，并对读取内容复读；竞争时拒绝该次并重新发现，进程身份变化终止。它不发输入、不改内存，也不授权显示。

初版只保存 `bCinematicMode` 原始存储字节；下述两轮尚未解码，不输出剧情 true/false。CameraActor 也不一律等于剧情。输出保存 EXE 哈希、模块基址与反射元数据，时间戳一致不代表游戏原子快照。后续受代码校验约束的解码见本文末节。

## 减少同次准备中的重复发现

`acquire_observer_preparation` 已在每次尝试建立新 Resolver 并调用 resolve；原先 AnchorSampler 的构造函数立即再次 resolve，重复校验磁盘哈希和全对象发现。现在通过显式 `prepared_camera` 传递同次发现提示，默认调用路径仍自行 resolve。`expected_camera` 保留独立比较意义；当前身份、Pawn/ViewTarget/相机双向关系、采样及末端复读全部执行，失败仍整套重新获取。

54项相关 Python 测试通过，含默认重新发现、准备提示不触发第二次发现、当前对象或关系变化拒绝，以及证书最后边界变化拒绝。首次补跑 UI 重取测试时，其旧 mock 未接收新增关键字而失败；补齐适配和同对象断言后通过，记录在 `prepared-camera-unit-tests.txt`。

实际 PID33292（`continuous-stereo-33292-20261015-210241-5319386f`）再次完成同进程重载，5367次 XR 提交、2397次复制、59.621秒，最大提交间隔12.458毫秒，清理/入口恢复/退出通过。原生准备15.983秒，相比 PID33072 的16.390秒变化很小；首次双目仍约35.594秒。这里只确认去掉重复扫描且实际运行通过，不把单次时差解释为稳定性能收益，更不宣称初次延迟已经解决。日志仍显示多次等待相机回到受控 Pawn。

## 剧情标记：静态汇编与运行字节核对

先查现有 KB，再使用历史 IDB 的私有副本 `analysis/ida/cinematic-bool-20261015/snapshot.i64`。原库哈希前后未变，独占 lease 已关闭。只检查布尔读取与复制函数，未重复全量反编译。

- 当前 PID33292 的 GNatives 表确认 slot0x2d 指向 RVA0x1d6ea4。127字节函数与历史快照及 IDA 字节一致，SHA256 `b71e2f794b38111292c497fa82c685f18a50822c44857853bb46acb6ad88609e`。汇编读取属性对象+0xd0的32位掩码，与实际值存储执行按位测试。
- 反射获得的 `bCinematicMode` 属性，其 vtable+0x2a0 指向 RVA0x1daba0。该25字节复制函数同样使用+0xd0掩码，仅更新目标对应位；当前运行字节和 IDA 一致，SHA256 `f4c26fb034bd7529efd10838092da31c9745e7b66f56cd054e793a1957a2915f`。旧库未定义此叶函数，使用 IDA 指令解码读取，未因此猜测空函数。
- 此实例反射属性的掩码为0x8000。新采样器每次核验函数表、vtable目标、两个函数完整字节哈希、标量布局及非零单比特掩码，全部纳入复读。它只产生诊断状态，不用于放宽原生渲染准入。

PID11788（`continuous-stereo-11788-20261015-212911-8164a1b2`）实际捕获 `CameraActor + cinematic=false`、`CameraActor + cinematic=true`、`Pawn_COGMarcus + cinematic=false` 三种状态。这直接说明不能仅凭 CameraActor 类名判断剧情。剧情相机接受样本的首次时间戳约5.495秒，下一次玩家相机状态约16.895秒；采样有空白，不证明整段连续状态。
