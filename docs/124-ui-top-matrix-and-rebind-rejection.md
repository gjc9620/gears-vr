## 文字、图标和材质的公共变换

在[根场景路线](122-path-choice-native-scene-route.md)基础上，复用资料库并补核对了少量原始字节，关闭此前 Tile 构造调用第五参数不明确的缺口：

| 路线 | 历史代码证据 | 结论范围 |
| --- | --- | --- |
| Tile／图标 | `1bc308` 从 canvas `+0x38/+0x40` 计算最后一个 80 字节栈项；在 `1bc3cb` 将其作为第五参数传给 `1c0e48` | 比较该栈项哈希；创建载荷时复制矩阵描述，不能只改矩阵而保留旧哈希 |
| 文字 | 已保存汇编与构造函数确认同样选择栈顶，并将 80 字节描述复制到载荷 `+0x80` | 后续弹出 canvas 矩阵栈不会修改已经复制的描述；不等于文字可见性已验证 |
| Material | `3a5548` 复制栈顶的 64 字节矩阵，重新计算哈希；`3a56b8` 由 R8 取得该描述，复制 80 字节到载荷 `+0x10` | 支持组合父变换经过材质载荷进入 SceneView；仍不代表所有材质 pass 或实际裁剪均正确 |

补导出严格按 SQLite artifact 1 的明确 chunks 进行，全部拼接字节 SHA256 与索引一致。原始输出在 ignored `analysis/ida/ui-pathchoice-20261017/1401bc308.chunks.json`、`1401c0e48.chunks.json`、`1403a5548.chunks.json`、`1403a56b8.chunks.json`。来源仍是 SHA256 `911ab9bcb24cc078420400369a78ffd3f747d915e42c4935a5c82c2dcecc6ae6` 的历史运行快照，基址 `0x140000000`，不是当前运行证明。

这使“在已认证根场景范围加入一个父变换，保留子节点相对位置”的路线更明确。仍未取得岔路子树的实际布局和裁剪坐标关系；RHI scissor setter `17490c` 的存在不能证明它参与该场景，也不能证明其矩形会随根矩阵变化。因此尚未启用实际 UI 平移，不宣布岔路位置修复。

## 机枪问题的下一次失败不再只显示超时

用户会话只记录 `Anchor guard acquisition deadline exceeded`，丢失了采样器已经保存的内部拒绝原因。`world_rebind_monitor._error_detail` 现在在原有、最长 512 字符的单行错误中附加最后一个 guard 的阶段、内部原因和尝试数；只使用现成异常证据，不增加进程读取、重试、日志频率或生命周期动作，不序列化身份／POV 原始图。

若严格读取本身成功但超过原截止，会明确标记迟到成功，避免误写成时间戳失败；损坏／缺失诊断结构仍保留原始错误。这项改变用于区分机枪重绑定的实际失败条件，不是机枪黑屏已解决的证明。

`test_world_rebind_monitor` 与 `test_world_rebind_runtime` 共 33 项通过，覆盖工作线程失败事件中的内部原因、不输出原始图、迟到成功、异常结构、长度与单行约束。原有重试次数、200ms 采样预算、信号发送和认证策略未改变。
