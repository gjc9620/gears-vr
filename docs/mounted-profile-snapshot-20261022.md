# 机枪切换配置的一次读取

继续缩短恢复路径中的重复工作。本轮从已集成的 WorldPrepare2 冻结源构建 WorldProfile1，没有启动游戏或模拟器；真机效果由用户统一验收。

## 修改

此前世界准备、Anchor、UI 和 crosshair 解析逐字段调用 `GetPrivateProfileStringW`。合成机枪配置有 939 个字段，最初五轮 Python 调用测量的中位耗时约 43.5 ms。随后使用原生组件排除 Python 调用开销，五轮查询中位耗时约 39.0 ms。

现在由原生准备线程在现有只读文件锁保护下，从同一个句柄一次读取完整候选。工作线程内的局部 Snapshot 为本次准备提供字段值，准备结束后销毁；没有跨候选、跨世界或渲染回调的缓存。元数据、Anchor、UI、crosshair 共用该读取结果，所有进程／owner／generation、身份、代码、实时内存和提交排空／GPU／世界门禁校验继续执行。

加速仅用于当前生成器的规范 UTF-16 BOM 文件及 ASCII 字段。引号、空白歧义、注释、重复键／节、Unicode 值等格式使用原来的 Windows API；缺失字段、大小写和缓冲区截断维持现有语义。读取和内存表具有大小／条目上限，加载失败清空旧状态。普通启动解析继续沿用原路径。

## 检查与测量

42 项原生／启动前检查通过。新增组件对机枪、流式 Level、过场机枪和普通状态的真实合成 INI，执行 36,340 项原 API 对照、大小写、不同缓冲区长度、特殊格式回退、写入／删除锁和失效清理检查。机枪组件另以原 API 和新读取路径加载配置并执行内存校验，共 233 项检查通过；既有离屏 D3D12、生命周期、第一人称、瞄准和世界交接组件检查保持。495 项 Python 检查通过，其中 353 项相关检查启用实际新 DLL，142 项启动器／打包检查。

原生组件中同一份 939 字段配置：原 API 查询中位数 39.0304 ms；Snapshot 首次载入 0.2489 ms，查询中位数 0.2249 ms，合计约 0.47 ms。这只描述本机缓存文件的配置读取工作，不是完整世界准备、GPU、FPS 或头显黑屏时长，也不建立完整“无延迟上机枪”验收。
