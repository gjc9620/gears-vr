## 修改

此前世界准备、Anchor、UI 和 crosshair 解析逐字段调用 `GetPrivateProfileStringW`。合成机枪配置有 939 个字段，最初五轮 Python 调用测量的中位耗时约 43.5 ms。随后使用原生组件排除 Python 调用开销，五轮查询中位耗时约 39.0 ms。

现在由原生准备线程在现有只读文件锁保护下，从同一个句柄一次读取完整候选。工作线程内的局部 Snapshot 为本次准备提供字段值，准备结束后销毁；没有跨候选、跨世界或渲染回调的缓存。元数据、Anchor、UI、crosshair 共用该读取结果，所有进程／owner／generation、身份、代码、实时内存和提交排空／GPU／世界门禁校验继续执行。

加速仅用于当前生成器的规范 UTF-16 BOM 文件及 ASCII 字段。引号、空白歧义、注释、重复键／节、Unicode 值等格式使用原来的 Windows API；缺失字段、大小写和缓冲区截断维持现有语义。读取和内存表具有大小／条目上限，加载失败清空旧状态。普通启动解析继续沿用原路径。
