记录日期：2026-10-11。

补充观察日期：2026-10-12。

状态：交互设计记录，留待后续实现。本文件不代表相关功能已经实现或验证。此前路线中“第一版先保留原版瞄准”的安排是技术验证阶段；本文记录最终希望实现的双手控制器交互。

## 目标与输入

第一人称 VR，头显提供自由观察和 6DoF 头动，双手控制器持枪瞄准。玩家不需要实际蹲下、站起或抬高身体来完成游戏内姿态切换。

| 输入 | 目标行为 |
| --- | --- |
| 左摇杆 | 普通移动、沿掩体移动 |
| 右摇杆上拨 | 虚拟站立，拨一次后保持 |
| 右摇杆下拨 | 虚拟蹲下，拨一次后保持 |
| 右摇杆左／右推住 | 向对应方向探身，松开收回 |
| 头显 | 自由观察，观察方向与武器瞄准方向分离 |
| 主手控制器 | 控制武器位置和朝向，扳机射击 |
| 副手控制器 | 辅助握持武器；抓掩体时离开武器 |

## 掩体与吸附

用户最终确定：交互上没有“进入掩体／退出掩体”状态，只有吸附。保留原版冲向掩体和吸附的功能，吸附用于辅助玩家到达掩体前并定位。角色在掩体前面朝掩体，但视点不被强制转向。

吸附不自动决定站蹲或探头。此前“低掩体默认蹲下、高掩体默认站立”的讨论已被后续修正取代：站立和蹲下由玩家通过右摇杆上下控制。

低掩体后，玩家下拨蹲下，上拨站起露头。左右探身由玩家主动控制，需受实际墙面和边缘限制，不能直接穿墙。

可复用原版站立、蹲姿、吸附及适合的移动约束，但是否需要内部掩体状态属于实现问题，不能在用户操作上恢复专门的进入／退出流程。

## 可选的左手扒墙探头

在右摇杆站蹲之外，增加可选体感操作：左手抓住掩体上边缘，向下压手，虚拟身体升高探头。玩家无需实际抬高身体。

讨论中的建议操作细节，留待原型验证：

- 左手靠近可抓的上边缘，按住握持键抓取，并给震动提示。
- 记录抓取时的真实控制器位置，以相对起点的下压位移决定探头高度，并限制最大高度。
- 手往回抬时降低身体；松开抓取后恢复操作前的姿态。
- 左手抓墙时不再辅助持枪，右手可以单手瞄准射击。
- 使用真实追踪空间中的控制器位移计算，不能让虚拟身体升高反过来改变计算输入，造成反馈循环或累积漂移。

该操作为可选补充，保留摇杆上下站蹲。需要测试反复操作的疲劳、单手瞄准，以及抓取过程中虚拟手与墙的接触表现。抓侧边缘拉动侧探仅为后续候选，尚未确定实现。

## 武器、视点与战斗一致性

- 主手控制武器，副手握持时辅助稳定朝向；头可以看向其他方向。
- 虚拟站蹲和探身位移需要统一作用于视点与双手，再叠加真实追踪。
- 枪口与弹道一致，实际掩体遮挡枪口时不能穿墙射击。
- 角色暴露、碰撞和受击判定需与虚拟姿态对应，不能只改摄像机而保留不一致的保护状态。
- 原版角色动画不能强制带动玩家视点转向、翻转或颠簸，真实头动持续生效。

## 翻滚替换为飞扑

用户希望把翻滚改为 Max Payne 风格飞扑，而不是保留翻滚动画只改镜头。

目标为方向输入配合闪避键触发飞扑，支持飞扑期间双手瞄准射击和短暂子弹时间。世界慢动作时，头显追踪及双手响应保持实时。

角色可以执行飞扑动作，玩家视点不跟随身体侧翻或扑倒旋转。飞扑移动仍可能造成不适，子弹时间不能视为不晕的保证，需要真实头显测试。

飞扑落地姿态、是否默认蹲伏、轨迹和具体时间参数尚未确定。

## 第一人称 Mod 参考观察（2026-10-12）

来源：用户对一个第一人称 Mod 的观察，尚未提供名称、链接或源码；本项目尚未独立验证。以下是观察到的表现，不是对其内部实现的确认。

- 鼠标向上抬时，镜头也会向上移动，可用于在掩体后查看敌情。
- 该 Mod 加大了 FOV。
- 翻滚时镜头表现为平移。
- 进入掩体后，角色面朝掩体。

对本方案的意义与调查方向：

- 上看与视点升高的联动提供了可参考的掩体观察方式。VR 方案仍保持头部观察与主动探头分离，不因玩家抬头自动升高身体；可调查能否把其升高机制改由摇杆或扒墙动作控制。
- 平移翻滚镜头可作为稳定闪避视点的参考，但不能据此认定已具备飞扑动画、飞扑中射击或子弹时间，也不能推断 VR 舒适性已得到验证。
- 面朝掩体的表现为姿态修改提供参考，但需区分角色朝向改变、摄像机位置改变和模型显示改变，具体机制待调查。
- 加大 FOV 是该平面第一人称 Mod 的做法；不作为 VR 方案中直接照搬的参数。
- 后续获得 Mod 名称、文件或源码后，再核实实现及复用条件。本次不改变已确定的交互，也不启动实现。

- 吸附如何解除，以及能否保留吸附而避免原版镜头和姿态自动接管。
- 右摇杆左右用于探身后的人工转向操作。

- 飞扑动画、轨迹、射击限制及世界时间缩放接口。
