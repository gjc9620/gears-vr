# 缩短调试启动流程

2026-10-11：已修改配置，用户已确认启动画面成功跳过。联网等待和直接地图入口仍待验证。

游戏的 `WarGame/Config/Steam/Cooked/Coalesced.ini` 是序列化字符串数组，
头部计数为 111，后面是 37 组文件名、内容、时间戳。每个字符串以有符号
32 位长度开头，负数表示 UTF-16 字符数（包含末尾 NUL）。因此不能直接
用文本编辑器保存。我们的工具严格检查整个结构、原始版本哈希并保存原始备份。

本次只修改两个配置内容字符串，其余字符串的原始字节保留：

  TheCoalitionLogo、UE3AnimatedLogo 四项 StartupMovies。保留 Startup 加载影片、

## 失焦自动暂停（2026-10-12）

原生普通代码中的 RVA 0x1e3f28 函数（运行时异常展开表给出边界）在
0x1e41ab 读取 UTF-16 启动参数名 NOPAUSEUNFOCUS；参数匹配结果存入 ebx，
0x1e41ea test ebx / jne 0x1e4286 跳过 ConditionalOutOfFocusPauseGame
命令构造与执行块。命令字符串引用位于 0x1e4255。
包脚本中的 WarPC.ConditionalOutOfFocusPauseGame / OutOfFocusPauseGame
调用 PauseGame；未找到对应的序列化 INI 配置开关。

因此调试启动器默认添加 -NoPauseUnfocus，不修改此处机器码或脚本字节。
