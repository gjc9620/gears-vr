# 右手 IK 对照试验边界

此文记录独立 6DoF 分支的下一步私有验证方案，不代表已完成游戏或头显验收。购买版单脉冲回执 `analysis/hand-ik-trial-runtime-1022d.json` 证明当前实例可以短暂设置原右手 World 位置目标并恢复原值：右手骨在脉冲期间沿目标 X 方向移动约 0.093 游戏原始单位，角色 `TickTag` 从 420 变为 421。但原待机动画同时带动双手；左手同帧移动约 0.018 单位，右手 250 毫秒后的自然位置也已偏离旧起点约 0.247 单位。单次相关位移不能归因为 IK，更不能证明头显可见。

保存的 `Engine.u` 对象盘点中，`Engine.SkelControlBase.ControlTickTag` 是 `BoolProperty`（artifact 3、object 24790），旧探针错当 `IntProperty`，因此旧日志 `tick_known=0` 只表示读法错误。修正版已改用当前实例反射核对的布尔读取，把角色整数 Tick 与控制器布尔标签分开记录；两者都只是活动遥测，不能单独证明控制器对骨骼产生效果。旧单脉冲候选在没有对照时只能以不可判定结束。

独立对照候选的预定顺序是 `S, +X, −X, −X, +X, S`。每个窗口都重新确认同一玩家、当前枪、网格、动画树、八控制器与空闲动作边界，先采不少于八个不同角色 Tick 的自然骨矩阵。`S` 以当前右手位置为目标，正反窗口分别在世界 X 加减 1 个原始单位；六次都使用强度 0.1、只写一次、下一次原 `PlayerTick` 前回滚。每次回滚须先由原 Setter 将强度归零，核对三元组，再比较并恢复本次拥有的目标值；随后至少 250 毫秒只读观察，才可进入下一窗口。不得延长 400 毫秒脉冲上限或逐帧重写。

日志须保存写前、写后、次帧回滚前、回滚后及自然观察阶段的左右手骨矩阵、角色世界矩阵、角色 Tick、QPC、世界时间、渲染活动标记和本次 owned 值。旧值恢复和动画姿态返回旧坐标是不同命题：待机动画可持续移动，不能以 250 毫秒后的右手位置与写前位置相等作为回滚标准。未完成六个窗口、任何 owned 字段变化、身份／动作／矩阵边界失效或清理失败时，试验不得出具完整回执，也不得将私有 DLL 作为可安全卸载。丢失写入所有权时不能用旧值覆盖新原版状态；自有测试宿主应结束它拥有的隔离游戏实例。

完整采样也只表示取得可分析数据，`effect_evidence=0`、`inconclusive=1`。离线分析先用脉冲前后**不同角色 Tick** 的自然样本按时间估计没有写入时的右手位置，计算脉冲残差，再与同跨度的无写入基线和 `S` 残差比较。只有正反脉冲各自重复出现相反符号、明显高于两种对照噪声且恢复后残差回到噪声范围，才可把当前实例的小幅 World 位置响应列为候选结论。预定私有阈值为每个方向残差大于 `max(0.03, 5×对照残差上界)` 原始单位；噪声过大即不可判定，不能事后放宽。渲染时间推进不代表骨骼进入最终画面；真实 XR 双手、旋转、持续驱动、原版固定动作争用和头显可见性分别验收。

本局保持 `bIgnoreControllersWhenNotRendered` 等渲染／动画调度标志原样。若正反对照仍不可分辨，先查已核对的动画求值后只读骨输出；不通过伪造渲染时间、强制求值或放大脉冲将不可判定改写为通过。私有运行必须遵守项目的购买版、自有置后静音、只读 tiny-output 监控与游戏退出清理规则。
