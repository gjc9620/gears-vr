单窗口采集：已查看实际截图，完整游戏客户区正确，去除标题栏及窗口边框。
源分辨率 1920×1080，输出 640×360。实际图片约 5–28KB，随场景变化；
最后版本的一张场景图 16,222 字节。截图和 JSON 元数据位于 Git 忽略的
`analysis/game-io/frames/`。

第一次采图发现 Windows DPI 虚拟化造成 960×540 裁剪。设置捕获进程为
Per-monitor DPI aware v2 后，完整 1080p 源画面正确。不是把错误裁剪当成降采样。

虚拟手柄：利用已有 ViGEmBus 驱动，手柄槽位 0。Start 键可打开暂停菜单，
截图显示 RESUME GAME；随后 A 键恢复游戏。不能仅靠“报告发给驱动成功”
断言游戏接收，所以另外用只读摄像机定位器核对输入结果。

超时长、NaN 轴值、未知按钮不触达设备。捕获程序最终版本编译成功并再次
成功采到 640×360 图；最终服务 stderr 无错误。
