# 0.1.0 首项完成：继续缩短上下机枪恢复等待

2026-10-21，实现和自动验证完成，已接入正常启动器使用的 Python 源码。用户之后统一做头显与上下机枪体验验收；本轮没有测量头显黑屏总时长，也不代表整个 0.1.0 已发布。

## 实现

在此前的一次完整采集、有界快速握手轮询及同次属性链复用基础上，继续减少 UI 类发现扫描的开销。`Resolver.discovery_class_candidates()` 对当前注册对象地址排序，按最多 64 KiB 的块读取发现提示，直接提取类指针，并在该次扫描中复用类种类判断。大块无法完整读取时，回退到原有的页读取及精确对象读取。

批量内容只用于寻找候选。UI 构建器仍重新读取选中对象的完整身份、名字与注册槽，保留反射字段、关系、脚本、代码和 native 最终验证。完成发现后，按新鲜身份的 `internal_index` 恢复原有证书顺序，并再次检查身份没有变化。原子发布、独占路径和同步落盘保持原有实现。源码与实测原型的规范化文本 SHA256 已核对相同。

正常启动器直接加载这些模块，无需额外测试入口。默认 native 仍为 `build-ads-anchor2-spin0`，SHA256 `fe928d7bab650b7672bd92b0d9ce7193ee2c9762a36250319ebcae4971729e8a`；XR 仍为 MountedLatency1，SHA256 `0a2b7f7dc6a65f8ee23c255423e5fac841726ac6f2ef9bc249ac8e5f4902d56c`。保留既有 FPS、ADS 和瞄准修复。
