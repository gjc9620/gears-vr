## The rationale and the boundary

Directly modify a lens matrix may omit the reverse array, group matrix and cropping data that the game calculates. This time lets the complete construction function of the game handle the parameters we provide, verifying that it can recreate the checked data that corresponds to the original view.22 Local ABI tests and primary reconstruction results of each parameter are complementary.

This round retains the original association status, original matrix and original size. The temporary view never adds a replaying assembly. It therefore proves that the current static mono-path structure and release capacity are not left or right eye rendering. Nor does it prove that all object fields are equal, GPU is complete, or that all lens modes are compatible.

The next step is to verify the independent state and restricted eye deviation in unsubmitted objects, check the derivative data generated by complete construction, and then consider giving the second view to actual rendering of roads. The world’s unit-to-mixing, left-to-right asymmetric projection and independent history still need to be validated individually.

# 完整源视图构造的原生验证

2026-10-12，原版单人关卡，PID 32032。第一人称 Mod 保持恢复状态，本轮不截图、不要求转镜头。

## 结果

游戏线程上仅执行一次未提交视图重建：用原视图的参数快照调用完整构造函数 `EXE+0x15e428`，而不是复制构造函数。临时对象使用游戏原生分配器，完成检查后调用源视图析构函数并配对释放。

- `attempted=2 stage=6 checks=255`：构造返回、主矩阵、关联指针、容器独立性、释放配对、原对象与集合保持不变等八项检查通过。
- 七组派生矩阵块 `+160/+1a0/+1e0/+220/+260/+2b0/+2f0` 都是有限值，最大绝对差为 **0**。
- 两个原视图数组非空；重建后的内容相同，存储独立。
- 20 秒记录 90,181 条，环形缓冲丢弃 38 条。观测 6,933 次 Present，未记录失败。
- 渲染对象构造、消费／销毁、矩阵准备三份既有分析均通过。停止时 `active=0`，十个启用入口的原字节全部恢复。

本地证据位于 `analysis/runtime/constructor-shadow-32032.*`，不提交 Git。专用分析工具为 `tools/native-capture/analyze_constructor_shadow.py`。

## 原理与边界

直接修改一块镜头矩阵可能遗漏游戏随之计算的逆矩阵、组合矩阵和裁剪数据。这次让游戏的完整构造函数处理我们提供的参数，验证它能重新产生与原视图一致的已检查数据。22 个参数的本地 ABI 测试和原生重建结果相互补充。

本轮保留原关联状态、原矩阵和原尺寸，临时视图从未加入渲染集合。因此它证明的是当前静止单人路径的构造与释放能力，不是左右眼渲染。也没有证明所有对象字段相等、GPU 完成，或所有镜头模式兼容。

下一步在未提交对象中验证独立状态与受限眼位偏移，检查完整构造产生的派生数据，再考虑把第二视图交给实际渲染通路。世界单位与米的对应、左右眼非对称投影和独立历史仍需要各自验证。
