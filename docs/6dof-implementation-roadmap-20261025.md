## 3. M1：第一人称

目标是先让人能稳定、正常地从角色眼睛看世界，不把自由双手或开火作为本项前置。

实施顺序：

1. **先闭合正常启动。** 复用已定位的手动启动 error 34 修复及 Capture.first_person_preview 重复键修复；确认候选实际携带正确生成方，配置只写一次。能力开关为 true 不等于实际第一人称已经选中，要确认最终视点通路。
2. **统一最终眼点。** 沿用现有 first_person_view、body_goal_view_adapter 与 C0 身体基准；以角色合法眼高和同次 HMD 姿态生成实际双眼视图，头部平移和转动各合成一次。去除游戏相机步态摆动对视点的额外影响，保留真实头动和合法移动／姿态变化。
3. **处理眼前遮挡。** 优先实现仅影响本地第一人称视图的头部／头盔等遮挡部位可见性处理，保留双臂和正常身体显示；具体可见性入口需沿现有渲染路径确认，目前不能声称已经具备局部隐藏。现有 120 mm 近裁剪只能作为辅助，必须同时检查近手和近处场景，不能靠持续加大裁剪或把眼点前推掩盖问题。
4. **交付独立可验收的 M1 包。** 启动、实际第一人称出图与正常停止形成一次基本检查；不引入完整掩体、枪口射线或骨骼诊断矩阵。

菜单新增要求：使用大的剧院屏，在打开菜单时基于稳定LOCAL/Stage空间面向玩家定位一次；头动不更新屏幕pose，重开或显式recenter可重定位。菜单可见、可交互及游戏双眼恢复都属于M1基本检查。

模拟器只做：进入一个普通可控场景 → 一次左右转头与小幅平移 → 正常停止。看实际 XR 左右眼和现有视点状态，不只看桌面窗口，也不以开关值代替出图。

用户真机三个动作：静止观察眼高和视野；左右转头并抬头低头；短距离移动／探身并观察明显晃动。反馈重点为“视点对不对、是否遮挡、是否明显漂移或不舒服”。通过后才收口 M2。

## 4. M2：左右手完整自由度

目标是左右手各有三轴位置和三轴旋转，能真实翻腕；手部操作不依赖先完成武器射击。

实施顺序：

1. **复用同次眼点换算。** 沿用 free_hand_eye_targets.h，将同一帧手柄 Grip 相对 HMD 的完整姿态转换到实际眼点所在世界，再应用固定的 Grip 到手腕标定；轴向和长度单位只换算一次。这里的 HMD 逆变换用于抵消眼点中已包含的头动，不把手绑到头上。
2. **左右侧分别处理。** 每只手独立保留位置、俯仰、偏航和翻滚，不只使用手柄朝前方向；一侧失去跟踪时，不让旧姿态继续驱动该侧，也不冻结另一只有效手。
3. **用现有双骨 IK 驱动双臂。** 肩点来自同一身体参考，固定上臂／前臂长度，只求关节姿态；无法触达时限制到可达范围，不拉长骨骼。保留现有唯一写入点与动画接管／交还逻辑，避免正常动画反复覆盖手部目标。
4. **交付累计的 M1+M2 包。** 验证两只可见手分别跟随，再观察“手不动只转头”时世界位置是否稳定。骨长、手腕方向和自然程度留给本次真机调校。

模拟器只做：左手移动／翻腕 → 右手移动／翻腕 → 固定手部位置并转头，随后正常停止。不展开所有角度、武器和动画组合。

用户真机三个动作：左右手分别伸向近处和远处；各自翻掌、转腕；双手停住时转头或探身。反馈重点为“位置是否贴手、翻腕是否正确、手臂是否拉长／翻折”。通过后才收口 M3。

## 5. M3：摸背后／摸裤兜换枪

沿用现有交互约定，先实现右手取枪，不同时扩展左利手、双持、取弹或投掷。

| 动作 | 目标 | 现有库存映射 |
| --- | --- | --- |
| 右手到右肩后，按一下 RGrip | 主长枪 | 原版槽 3 的当前武器 |
| 右手到左肩后，按一下 RGrip | 第二把长枪 | 原版槽 2 的当前武器 |
| 右手到左裤兜，按一下 RGrip | 手枪 | 原版槽 0 的当前武器 |

右裤兜原有手雷槽映射保留，但取雷／投掷不计入本次“换枪”交付。按 Grip 才触发，不因手掠过身体就自动换枪；取枪后沿用现有锁定握持，不要求一直捏住 Grip。持枪返回原槽再按 Grip 的既有收枪行为保留。

实施顺序：

1. **让槽位稳定且够得着。** 复用 body_slots.h 和现有臂展校准，用稳定躯干参考放置左右肩后与裤兜范围；需要校准时沿用一次 T 姿态流程。头部单独转动不能拖走槽位；触达位置由用户本轮真机反馈调校。
2. **补齐一次动作的状态转换。** 手进入槽位 → Grip 新按下 → 锁定一个目标槽 → 请求原版换枪 → 等实际装备完成 → 建立新持握。使用按下边沿与已有等待状态防重复；动画忙、空槽或丢跟踪时不生成假的成功。
3. **以原游戏物品栏为准。** 复用 WeaponEquipmentModel、equipment_switch_mailbox 和原版装备调用。只有真实 current_weapon 与目标一致、切换结束，才算取到；新拾取的枪跟随原槽身份，不复制物品、不凭手势改库存。
4. **补上换枪后的可见持握。** 当前 body_c0_hands 和 body_mount_equipment 部分路径只接受 free_hand／held_lancer 或 Lancer 资产。本项必须覆盖实际验收用的两支库存长枪及手枪的基础握点／模型显示／跟手；不能只把库存切了或收到 Grip 就报完成。优先复用现有握点资料，仅补必要的资产映射，不借此开展逐枪射击、换弹等机制。
5. **交付累计的 M1+M2+M3 包。** 在同一普通场景做一次长枪 → 第二长枪 → 手枪 → 原长枪的切换，查看实际装备和手中模型；只保留本轮需要的失败原因与日志。

模拟器只做上述一轮换枪，核对实际装备和可见模型，并带看第一人称／双手没有明显破坏。模拟器中的校准数据须明确是隔离夹具，不覆盖用户真实校准。

用户真机三个动作：右肩取枪并拿到面前；左肩换第二把长枪；左裤兜取手枪再切回。反馈重点为“摸不摸得到、会不会误切、拿到面前是否就是目标枪并正确跟手”。开火命中与准星不作为此项通过条件。
