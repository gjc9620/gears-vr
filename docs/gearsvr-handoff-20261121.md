## 真机反馈与接手验收

| 范围 | 真机反馈 | 期望与待核对项 |
| --- | --- | --- |
| 6DoF、移动、肩部 | 多次肩部取弹后出现无法正常走路或走得极慢，仍能用右摇杆转视角。有时能走动和转视角，但 6DoF 手消失、手势及换弹失效，表现像平面版 Xbox 手柄模式。重启游戏并重新进 VR 可恢复。左肩取不到枪或弹药，榴弹发射器也受影响。用户感觉肩部和换枪吸附范围太小，身体仍可见。 | 用已有日志按时序核对输入路由、追踪状态、虚拟手发布、肩部和武器交换状态及移动限速，再复现多轮肩部取用。恢复稳定移动、虚拟手与交互，核对第一人称身体隐藏及肩部 Volume/Snap。 |
| 兽族步枪 Hammerburst | 手臂水平时枪约上翘 80°；开火时枪口和整枪上下跳；拉柄无效，黄色抓握区太小，弹匣拔不出。 | 换弹只保留直接拔弹匣、插弹匣。移除拉栓和其他活动部件交互，扩大有效弹匣抓握区，验收枪身、射击稳定性和连续换弹。 |
| 黎明之锤 Hammer of Dawn | 枪身约上翘 60°。 | 同一套 Pimax 姿势对照不同武器的挂点、局部前向轴和瞄准。用户提到角度正常的参照，原话是“Launcher”，具体所指待核对。Pimax 通用问题尚无证据。 |
| 榴弹发射器 Boomshot | 左肩取不到补给，弹匣/装填件抓不住且换弹流程有问题。双持能抓但姿势别扭，移动双手后枪不跟随。 | 复核肩部供给、装填件抓握和连续换弹，双持时武器随手移动，调整双持姿势。 |
| 普通手枪 Snub | 枪口外观看起来水平，子弹向上打。双持闪烁，弹匣抓握/吸附区太小、抓不住且上弹困难；约重复上膛两次后无法开火。 | 取消双持姿势，修正实际弹道方向并与可见枪口对齐。扩大弹匣 Volume，核对吸附与装填状态，验收多轮换弹后仍能射击。参考已采集的 GrabPose 和工作台里武器与弹匣的相对位置、抓握点。 |
| 左轮 Boltok | 无法开火，枪口约上抬 10°；弹巢无法打开/取出，未完成换弹。用户怀疑当时满弹。 | 单独验证枪口和开火门控，并分别验证满弹、部分装填和空仓下的弹巢与换弹。满弹是否相关待查。 |
| Frag / Smoke | 破片手雷不论投掷速度或朝上投，落点都约在两三米；取出时柄在上、弹体在下，方向倒了。其余破片交互用户认可。烟雾手雷取出后的上下方向与效果正确。 | 核对释放速度、方向与游戏内抛物线；测试轻抛、快投和向上投的差异。修正 Frag 取出朝向，并复核 Smoke 原有表现。 |
| 掩体 | 左边缘切成左手射击；进入时持枪可能消失或回到库存。低掩体空手抓探头失败，能开火但帧率低，掩体中移动卡顿。高掩体物理左右探头可用但有卡顿。 | 只保留远程吸附进掩体、掩体之间快速移动、掩体内移动。探头依靠身体实际移动。删除空手抓握触发的上下左右探头和原版边缘换手逻辑。验收进出时保留手持武器、右手可开火，以及移动和探头流畅度。 |
| Launcher 停止 | 按「停止」后退出过程很慢。 | 用分阶段时间找出等待发生在游戏退出、Native/XR 清理还是启动器状态刷新，保留正常清理，缩短停止耗时。 |

建议先抓能让所有手势同时失效的 6DoF 状态切换和肩部取用，再分模块处理姿态、装填与掩体。模拟器用来复现状态和验证回归，Pimax 真机确认角度、跟手、可触达范围和流畅度。每项记录对应构建、首次失败、实际动作结果与正常退出。
