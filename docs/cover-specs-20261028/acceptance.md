## 最小回执

后续诊断以事件为中心，记录：context/basis generation、Scene/Tick/compose/invocation、input sample与press token、intent/commit/from-version、抓取edge、requested/accepted offset、query verdict和geometry generation、same-pose view/hit/muzzle版本、原state/CA/CD、首次拒绝原因、正常结束／恢复结果。对象地址、脚本、私人运行信息仅在 ignored analysis 中；公开描述用符号和版本。

每次结论分别标注：实现完成、编译通过、基本动作达到、具体实际结果、清理、候选交付和用户头显反馈。本轮全套运行证据栏为未执行，不能由离线索引检查替代。

第二轮的[规格参考模型结果](contract-check-results.json)为28个合成时序案例、78个断言与3个位移合成例通过；它没有执行现有C++或上述任何实际游戏场景，也不关闭U1–U4。
