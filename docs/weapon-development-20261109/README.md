- 不把原动画角度、历史容量／时间当成控制器阈值或当前实例事实。
- 用户本轮已将本批有物理换弹武器的完美期限明确统一为4秒，覆盖旧原完美截止合同；无常规换弹的武器不新增换弹流程。
- Troika 的自动 Reloading 不等同于手动换弹，也不能直接改名为自定义过热系统。
- 本批不增加新的左撇子布局、快速装弹器、传统拉弓弦、射速／伤害平衡或在线联机保证。
