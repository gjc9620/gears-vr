## 中文

# Hammer of Dawn 黎明之锤：交互需求与开发验收

日期：2026-11-09。用户已确认并授权开发；机构尺寸、角度、握点和接触范围由本枪会话自行考虑及验证。无常规换弹，不新增四秒流程。配套[公共合同](common.md)。

## 1. 操作目标

持枪指向原版允许的目标，按右扳机让原系统锁定、预热并照射；松手或中断完整停止。**没有普通换弹，不新增弹匣、电池、充电手势或R3奖励。**

## 2. 玩家操作步骤

| 阶段 | 玩家动作 | 必须结果 |
| --- | --- | --- |
| 取枪 | 对应肩槽点按RGrip | 正常主握；原版可选装备／区域限制保留 |
| 指目标 | 转动武器，头显自由观察 | 原实际目标查询与可见指示使用相同武器起点／方向，不能仅移动激光特效 |
| 开始 | 合法源下按住R2 | 原BeamManager启用和目标条件成立后进入预热；非法目标不强制照射 |
| 持续 | 保持按住并对准 | 原目标保持、容错、预热／冷却和Beam推进；不靠头部方向追踪目标 |
| 移开 | 按住时把武器移到非法位置 | 原InvalidTarget处理撤销／停止；回到目标后的行为沿原状态，不自造自动重锁规则 |
| 停止 | 主动松R2 | 结束目标、Beam和循环音／反馈，关闭本轮瞄准激光，无残余伤害 |
| 再用／收枪 | 新按扳机，或原槽收枪／切枪 | 重新走原资格；旧请求不能作用到新武器 |

## 3. 限制与反馈

- 室内、BeamManager禁用、无合法目标、原版禁止开火时均保持原限制；不设置全局“永远合法”。
- R3不取弹、不开始普通换弹；左肩不生成本枪虚构弹药。
- 左手支撑可复用公共持枪，但不会独立改变目标选择、预热完成或原光束权限。
- 失追、离手、暂停／剧情接管、换世界，采用已认证的完整停止语义。恢复后旧按住不自动重启新的照射。
- 区分“无合法目标”“预热中”“照射中”“原恢复中”，优先保留原指示／声音与简洁提示。
- 画面的标记移动与实际受伤对象必须一致；停止以原状态和效果读回证明，不能只隐藏光束。
- 静态paint time=1.2秒、grace=.25秒只是原资料，实际值按本实例；不新增额外VR锁定等待。

## 4. 模型与停止链

保留原cog_hod_mesh、Trigger及原粒子／Beam，手指与扳机接触自然。原GetTraceImpact实际消费武器起点与Aim，必须接入真实查询。

正常停止包含原EndFire下的NotifyInvalidTarget／NotifyStopFire／TurnOffTargetingLaser，BeamManager最终中止当前Beam。应依原上下文调用，不把函数名直接当已认证ABI；声光特效关闭和实际伤害停止都要验证。

## 5. 必须验收

1. 合法区域／目标：指枪、按住、原预热、实际照射和效果。
2. 同一目标仅转头，武器未动时基础目标不变；实际查询与标记一致。
3. 非法区域、非法目标和被阻挡目标不越权照射。
4. 按住移开目标，原失效处理正确；返回按原状态恢复。
5. 松R2、失追、收枪、切枪、菜单／死亡／读档后无残余Beam、循环音或待发。
6. 取消后保持旧按住不能新照射，真实松开再按才重新请求。
7. R3／左肩不会产生换弹或奖励，主副手贴合和双眼反馈可辨。

## 6. 实施入口与待核对

复用 weapon_hammer_of_dawn_interaction.h、具体WEAP_HammerOfDawn的BeginFire/EndFire/GetTraceImpact/Tick/UpdateFX及原BeamManager。待核：可用地图和目标、真实停止链参数／所有权、目标保持边界、原反馈可读性；光束是否适用既定单／双手倍率需沿现行主线合同核对，不擅自改变。
