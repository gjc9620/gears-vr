# Gnasher 霰弹枪：交互需求与开发验收

日期：2026-11-09。状态：用户已确认，授权开发。完美换弹统一4秒；机构尺寸、角度与接触范围由本枪会话自行标定。配套[公共合同](common.md)。

## 1. 操作目标与已定规则

右手持主握把，左手支撑枪前部、逐发取弹和装填；射击由右扳机触发。它使用**杠杆下掰／回位**，不是前护木直线泵动。原 Weap_Shotgun 的散布、多弹丸、射速和伤害路径保留。

## 2. 玩家操作步骤

| 阶段 | 玩家动作 | 必须结果 |
| --- | --- | --- |
| 取枪 | 在对应肩槽点按 RGrip | 原库存枪绑定当前手；已装弹的初始枪可正常射击，不先强迫空做杠杆 |
| 开一枪 | 机械就绪时按 R2 | 以一次真实原射击确认进入待循环；多颗弹丸不能算多次循环 |
| 射后循环 | 左手按住 LGrip 扶前端；右手仍持握把，相对支撑点向下掰，再回到闭锁位 | 原杠杆跟随；两个端点及回位实际完成后才恢复下一发 |
| 取第一发新弹 | 缺弹时左手先松开副握，移到左肩新按 LGrip | 预留一发完整霰弹；原版接受本轮装填时开始计时，不先按 R3 |
| 插入一发 | 持续 LGrip，按正确方向从实际入口连续送入 | 库存确认只增加1、备用只减1；仅接触不完成 |
| 继续装填 | 已插入件交接后，松 Grip，再到左肩新抓下一发 | 本轮最多 q=min(3,C−L,S)，目标在开始时确定 |
| 结束装填 | 左手空出并重新扶前端；右手完成下掰／回位 | 装1／2发也可提前结束，已装保留；未达到目标只普通完成 |
| 恢复开火 | 最终回位并获得实际闭锁确认 | 不额外再要求一次相同杠杆；之后才能射击 |

## 3. 数量与特殊情况

- 静态资料容量8、备用上限31仅作参考，运行以原实例为准。
- L=2、S=10时本轮目标3，只能装到5；不是一次自动补满到8。
- 同例只装1发并提前闭锁，结果L=3、S=9，普通完成；不能将目标改成1骗取完美。
- 若只缺1发，目标就是1，正常完整完成可按可信期限判定。
- 原本射后待循环再开始装弹，最终杠杆闭锁合并为一次，不重复收尾。
- 没有备用仍可完成已有射后循环；没有新弹不触发换弹奖励。
- 未装任何弹就退出，不补弹、不扣弹、不授奖。
- 原有弹药保留，未插手持弹松手归还预留；失追后已插入数量不能丢失或重加。

## 4. 手部、机构和反馈

实际抓点、支点和完整行程须标定。原动画约32.43°是机构资料，不是直接采用的手柄角阈值。左手未支撑、只抖枪、只旋腕、泵动护木不能冒充合法杠杆循环。

当前步骤分别提示左肩、装填入口或杠杆区域；已满／零备用给一次反馈。原杠杆实际到位才给完成反馈。完整封口霰弹须用已制作原创件，不拿空壳代替实弹。

失追／松开支撑时不推进杠杆；恢复后新抓握并按当前机构续接，不能自动跳到回位。原 ShotgunCocking 计时器先结束也不能代替手动循环。

## 5. 必须验收的具体场景

1. 初始有弹取枪 → 射一发 → 直接再扣扳机被阻断 → 真正下掰回位 → 再射。
2. 下掰未到底或未回位、左手未支撑、泵动动作，均不能解锁下一发。
3. L2/S10补三发到L5/S7；少装1／2发后闭锁，数量正确且普通完成。
4. 仅缺1／2、备用不足3、S0、已满，均按实际缺额处理。
5. 第二发已提交后失追／收枪，恢复保留已装数量，无自动补满或重复扣弹。
6. 待循环与装填同时存在，只做一次最终杠杆；正常完成后真实射击并核对实际多弹丸原链。
7. 双眼查看主手、支撑手、持弹、入弹、杠杆和回位；计数正确不能代替自然贴合。

## 6. 实施入口和需核对项

复用 weapon_gnasher_mechanics.h、原 b_Shotgun_Lever、ShotgunCocking 与 FinishedCockingShotgun；对齐当前库存事务／原件后端，不复原旧试验入口。

本枪会话自行核对并标定真实支撑点、右握把相对旋转约定、装填口、弹药比例、接触范围和原计时器接管／一次闭锁。完美期限已定4秒，按公共合同从原接受计时；提前闭锁未满目标仍只普通完成，不等待原完美窗口。
