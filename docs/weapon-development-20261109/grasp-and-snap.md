# 吸附体验与逐部件抓握姿势：强制产品合同

日期：2026-11-09。用户明确追加：“注意实现吸附用户体验、抓握姿势，每个部件都要有对应抓握姿势”。与common.md及逐枪需求共同执行。

## 1. 覆盖范围

“每个部件”指玩家实际可接触、抓取或操作的部件。每项要有独立定义和对应姿势；联动子件可属于一个实际抓点，但必须明确归组，不能用未定义的全枪通用握拳覆盖。

| 武器 | 最少需列入本枪抓点／姿势清单 |
| --- | --- |
| Gnasher | 右主握把／扳机指、左前支撑、单发实弹、装弹时持弹姿势、杠杆下掰及回位时的主副手姿势 |
| Boomshot | 右主握把、左副握、装填机构开放／关闭抓点、原装填组件、入座阶段持件姿势 |
| Torque Bow | 右主握把／扳机、左支撑、原箭抓点、沿槽装箭姿势；原弓臂联动不新增无意义抓点 |
| Hammer of Dawn | 主握把／扳机指、实际副手接触部位；不凭空添加装填件 |
| Troika | 左右机枪柄分别定义、触柄进入时接触姿势、双握控制和右扳机手指 |
| Smoke | 实际原主体／链雷持握、裤兜取用、准备及松手张手；有原贴附交互时另定义，不能把全部链节当独立可抓物 |

已有Lancer、HB、Snub、Boltok、Longshot、Frag沿相同原则逐项覆盖主握、副握、弹匣／实弹、套筒／栓柄／卡扣等实际交互件；掩体的抓边点也需要对应贴合姿势。

## 2. 吸附体验

接近时帮助找到真实表面与正确朝向，不产生越权控枪或机构动作。区分被动吸附、真实Grip授权、保持和脱离，提供适当获取／保持迟滞，避免边界抖动、手瞬跳、来回抢部件或远距离拉手。

真实抓握后跟随对象且稳定；松开按该件既定规则释放、保持被动吸附或脱离，不能所有部件统一强制粘住。当前已持弹匣／子弹时不被旁边护木抢走。按住旧Grip从区外返回不能伪造新按下。

吸附只辅助合理小偏差，不补造完整插入行程、闭锁、循环、库存或原版进入权限。Troika空手触真实柄可请求进入，但未原占用确认不得强制绑定双手。距离／角度／范围由各会话根据原模型和实际反馈自行考虑标定，禁止靠扩半径掩盖几何错误。

## 3. 每件GrabPose定义

清单至少记录：部件身份／抓点、位置与朝向、掌心接触面、拇指包握、四指闭合、食指／扳机职责、腕部方向、所属手、吸附／抓稳／操作中／释放的姿势及过渡。可复用authored手型基础，但逐件适配表面、直径、姿态和用途。

禁止明显悬空、穿模、掌指张开但实际已抓住、握错方向及袖口大面积穿枪。保持固定骨长，不靠拉长手臂／骨骼修贴合。按物体几何标定控制器到物理腕与皮肤手型的关系；机构测量不能从已被吸附修饰的骨骼回读形成自证反馈。

## 4. 模块化

公共层复用同一手部仲裁、Snap／Grab状态、通用姿势提交及唯一C0／Native写入点；各枪独立提供抓点、尺寸、逐件GrabPose、机械关系与反馈。新增通用能力不得依赖具体武器，不能为各枪加第二骨骼writer／Hook，也不能侵入其他武器私有状态。

产品不依赖测试脚本。姿势定义、机械判据、库存提交和显示分开；显示吸附成功不授予机械控制，已取得真实控制也不等于手型画面通过。

## 5. 必须验证

每个可交互部件分别记录：靠近吸附、未按Grip不越权、真实抓握、随枪／件移动旋转、机械动作中稳定、松手与再次抓取、超保持范围脱离、失追／切枪／暂停恢复。根据本件实际规则判断，不追加不存在的功能。

通过游戏／模拟器直控与双路录像检查实际主手、副手和每个部件，从能看到接触面的正侧及必要斜角抽查掌、拇指、指根、手指、腕和袖口。遮挡看不清就保留未验收；目标矩阵、CPU数组、成功grant或计数不能当作像素贴合证据。头显舒适度单列，不以模拟器通过代替。
