## 2. 输入和手部意图

- 普通手持枪：右手在右肩取武器1、左肩取武器2；点按 RGrip 保持持枪。原槽再点按收枪，其他有效槽切枪；空中误按不丢枪。槽位由原库存决定。
- 左手到左肩，按住 LGrip 取当前枪对应弹药；与右手左肩取武器2区分。
- 左手同一时间只持一个对象／机构／支撑点。先实际松开，再用新 Grip 抓下一个目标；不能扫过机构就开始换弹。
- 手靠近、被动 Snap、真实 Grab、控制机构是不同状态。被动吸附不授予控枪、拆件、库存或机械推进权限。
- 副手支撑沿现有公共仲裁；退出支撑后主手继续控枪。Troika 的双握把资格与普通枪不同，按专属文档。
- 头显负责观察；武器／炮位姿态负责基础方向。LT 保留现有瞄准语义，不将枪拉到眼睛中央；不能顺带探身。
- 不要求 R3 开始物理换弹。可选辅助与物理动作共用一次事务，不重启计时；扭力弓 Charge 中 R3 只取消。
- Smoke 持续 RGrip、松开投掷；普通枪点按保持，不能把两者混用。

## 3. 库存与装填交接

以原实例容量 C、已装 L、备用 S 为准；旧文档数值只作静态参考。取新弹先预留，插入确认才提交；未插松手回收显示并释放预留，备用不减少。已插只按实际数量入账，重复接触／通知／回执不能重复扣弹、补弹或奖励。

插入需同时有正确物件、入口、方向、连续行程和当前有效抓握。可用导向和适当吸附帮助对准，不能靠接近、定时等待或空手碰入口直接完成。插入成功后必须清楚交回部件显示／控制，持续 Grip 不能凭空再领一发或同时获得副手租约。

零备用左手保持空手，一次有效取弹请求给一次“No ammo”反馈。已满不生成多余弹药。任何额外射击均需真实射击许可。

## 4. 机械和完美换弹

原机构到位／关闭与游戏弹药提交分别确认；有弹但未闭锁／循环未完成仍禁射。原自动换弹与射后计时器不能跳过物理动作；超时不自动补满或新增卡壳惩罚。

用户本轮明确：本批有物理换弹的 Gnasher／Boomshot／Bow 完美换弹统一为 **4秒**。原版接受首个有效本轮装填动作开始，以原游戏时间计时；在4秒截止或之前完成最后必要机械动作且达到本轮装填目标，才可奖励。超过4秒仍正常完成，不自动补弹或卡壳。装弹与原奖励回执各一次，不使用原完美窗口或ReloadDuration替代4秒。暂停沿原游戏时间，失追和重新抓握不重启时钟。黎明之锤、Troika和Smoke没有常规换弹，不因此新增四秒流程。

Gnasher 提前关闭、未达到本轮目标只普通完成；目标不因提前结束缩小以制造完美。纯射后杠杆、满枪检查和无新弹检查不重复授换弹奖励。

机构尺寸、角度、接触范围、握点和行程由各武器开发会话根据实际原模型／动画／运行反馈自行考虑、标定和验证，无需逐个向用户询问。不得借标定削弱身份、输入时效或用错误几何放宽范围。Troika空手触碰真实机枪柄即可请求原版进入，无额外进入按钮或Grip前置；Smoke质量明确为2kg，真实速度不按质量缩放。

- 无弹、机构没关、待循环、目标非法等应可理解，避免只给开发错误码。

- 显示目标不是实际结果，数学吻合不是皮肤贴合证明。验证规划使用生产几何，结果检查实际组件／骨架／原调用与库存。

## 6. 中断

| 事件 | 必须行为 |
| --- | --- |
| 主动松开部件 | 停止本次驱动；按该机构规则保持真实中间状态或回位；不靠松手跳过未完成行程 |
| 失追／过期／回中／空间换代 | 取消待执行运动与边沿；已提交库存保留，旧输入不续期；恢复后新抓握 |
| 切枪／收枪 | 原实例的已装数量与未完成机械状态保留；不把旧租约转给新枪，不自动继续开火 |
| 死亡／读档／换世界 | 按新实例重新绑定；旧物件、令牌、计时和待发请求不能作用于新对象 |
| 调用结果未知／部分写入 | 先读回和保留恢复责任；不直接重试生成、扣弹或授奖 |
| 手雷已生成／箭已发射 | 交给原弹体；不能借取消销毁、退款或刷新引信 |
