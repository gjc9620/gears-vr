GearsVR 0.0.1

Install and play

1. Before installing, open the game normally. Set Display mode to Windowed / Borderless, Frame rate limit to Unlimited, and DLSS / DLAA to Off. Apply the settings, then exit the game completely.
2. Extract everything from the mod ZIP directly into the game's root folder. GearsVR Launcher.exe and the Binaries_x64 folder must be next to each other. Keep runtime and tools with the launcher.

Gears of War Reloaded/
├── GearsVR Launcher.exe
├── Binaries_x64/
│   └── GOWDE-Steam.exe
├── WarGame/
├── runtime/
└── tools/


Place the launcher beside Binaries_x64, not inside it. Don't leave the mod inside an extra GearsVR subfolder.

3. Connect your headset and open GearsVR Launcher.exe. Game path should fill in automatically. System OpenXR runtime is the default; VD users can select Quest 3 / Virtual Desktop (VDXR) if needed.
4. Click Start VR and play with your keyboard/mouse or gamepad.

Quick notes

- Tested: Act 1, KRVR + Apple Vision Pro, and VD + Quest 3. Supported game EXE: 1.0.381.6947.
- Adjust: lower Render scale if it feels choppy; try Camera closer = 0.4 for a closer view. Restart the game after changing these.
- Known issues: mounted machine-gun entry/exit may pause for about 2 seconds. DLSS isn't supported yet; keep it off.
- Bugs: click Export logs and send the ZIP to me or post it on Discord, with your headset, GPU, and what happened.

安装与启动

1. 安装前先正常打开游戏：显示模式改为窗口化或无边框窗口，帧率限制改为不限制，DLSS / DLAA 完全关闭。应用并保存设置，然后彻底退出游戏。
2. 将压缩包的全部内容直接解压到游戏根目录，目录结构见上方示例。GearsVR Launcher.exe 必须和 Binaries_x64 文件夹并排，不要放进 Binaries_x64，也不要再套一层 GearsVR 文件夹。runtime、tools 要一起保留。
3. 连好头显，打开启动器。游戏路径会自动填入，默认使用系统 OpenXR；VD 用户也可手动选择 VDXR。
4. 点 Start VR，使用键鼠或手柄游玩。
