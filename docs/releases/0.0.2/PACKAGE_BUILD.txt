修复与日志
执行策略只作用于启动器拥有的PowerShell子进程；支持带下载标记的脚本，不更改系统策略或删除下载标记。
为真实Steam游戏提供正确App ID上下文；多设置文件时按当前Steam账号选择。
EXE自动识别覆盖游戏根目录、EXE同目录和一层Mod子目录，已有有效路径优先。
启动脚本输出显式保留，GUI展示失败原因；解释器探测统一UTF-8，支持中文目录的随包Python。
新startup_diagnostics模块记录逐阶段耗时、组件指纹和实际Steam子进程上下文；按创建时间核对同一个游戏进程。
线程返回码与游戏进程退出状态分别记录；仅提取当前prime的有界状态，不导出地址或入口字节。
Export logs新增build-info.json、startup-attempts.json、startup-summary.txt，包含最近三次启动，无VR会话也能导出。
诊断写入失败不改变启动和清理。完整中英文变更记录见根目录CHANGELOG.md及线上Release。
