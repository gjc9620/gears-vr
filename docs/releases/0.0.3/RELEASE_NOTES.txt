GearsVR 0.0.3 — First-person preview, Playground and compatibility
2026-10-23

- Add switchable first-person preview: L3 + R3 on a gamepad or E + R on the keyboard. Unscoped sniper weapons can use the preview; the original scoped camera is preserved.
- Add right-stick deadzone control, 0–50 percent, default 2 percent.
- Add happyotaku playground to the main menu: eleven weapons/throwables, six respawning targets, a mounted gun and unlimited reserve ammo, with normal and active reloads.
- Remember up to ten game paths in an editable dropdown, with browsing and autocomplete.
- Improve cover-aim state handling and add the missing binocular sniper-scope material route.
- Improve mounted-gun/world recovery and stereo frame tracking/transfer. The user considers the current mounted transition delay acceptable; zero delay and 90 FPS are not claimed.
- Improve Steam online/offline settings selection and per-installation configuration handling, including compatible versions found "elsewhere". 😉
- Include SteamVR menu-format compatibility. Final XR color behavior follows the verified rollback described in the release build record.
- Retain the 0.0.2 startup compatibility, Unicode-path and bounded diagnostic-export fixes; launcher and startup reports now identify as 0.0.3.

This is the development content previously called 0.1.0, released under 0.0.3 at the user's request. It does not include experimental DLSS, full 6DoF weapon handling or physical reloading.
First-person and Playground have recorded game/simulator evidence; individual fixes retain their documented headset/graphics acceptance boundaries. Later chapters and all hardware/runtime combinations have not been verified. A local left-eye-edge white-flash report remains tracked; no complete physical-headset fix is claimed by color selection or offline tests alone.
See README.txt for installation, controls, updating and reporting problems.
