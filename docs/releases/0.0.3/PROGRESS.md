用户明确要求等待另一个会话完成闪烁相关回滚后再发版。已找到正在执行该工作的「排查启动器未进入游戏」，其目标是恢复原有颜色路径。最终native／XR清单、源码冻结及打包须以该会话完成后的默认值为准；本次不自行更改其XR代码或回滚方案，不将此前统一sRGB试验写为已发布功能或闪白修复。当前仅准备版本标识、发布说明和工具支持，尚未创建线上0.0.3标签或Release。
