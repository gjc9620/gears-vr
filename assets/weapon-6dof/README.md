# Original VR weapon part prototypes

`lancer-starter.glb` is a new 704-triangle, three-node pull starter built by
`tools/weapon-models/build_lancer_starter.py`. The socket stays on the Lancer;
the small T-grip follows the left hand and the cord extends along local +X.
Its shape and materials are original, not extracted from the retail weapon.
The existing `b_AR_Chainsaw_Handle` is retained as part of the gun. This
prototype is not loaded by the game yet; socket placement, hand reach, cord
length and yellow guidance need game and headset checks. Rebuild with
`py -3 tools/weapon-models/build_lancer_starter.py` and validate the
committed bytes with `--check`. A local preview may be written under ignored
`analysis/` with `--preview` when Pillow is available.

## Gnasher round

`gnasher-round.glb` is a new procedural model generated by
`tools/weapon-models/build_gnasher_round.py`. It is a sealed round for the
future left-hand physical reload, not a copy of the game's open ejected shell.
The provisional envelope is 33.7 mm in diameter and 113.5 mm long, matching
only the measured bounds of the checked retail spent-shell resource. Geometry,
folds, primer, colours and materials are new. Its local +Z axis runs from the
base toward the sealed tip; coordinates are metres.

This is an asset prototype. The game does not load it yet, and the chamber
fit, hand grip, visual scale and final art need in-game and headset checks.
Rebuild deterministically with `py -3 tools/weapon-models/build_gnasher_round.py`
and verify the committed bytes with the same command plus `--check`. A local
preview can be generated under ignored `analysis/` with `--preview` when
Pillow is available. No original package geometry or textures are included.

## 纳舍尔圆形

`gnasher-round.glb` 是一种由
`tools/weapon-models/build_gnasher_round.py`。这是一圈密封的圆形
未来左手物理重装,而不是游戏开放弹出壳的复制件.
临时信封是 33.7 直径和 113.5 毫米长, 匹配
仅是所检查的零售废壳资源的测量范围。
折叠、底线、颜色和材料都是新的。它的局部+Z轴从
坐标是米。

这是资产原型,游戏尚未装入, 和密室
适合,手握,视觉尺度和最终艺术需要游戏和耳机检查.
以确定性的方式重建 `py -3 tools/weapon-models/build_gnasher_round.py`
并用相同的命令加验证已执行的字节 `--check`本地
可以在忽略下生成预览 `analysis/` with `--preview` when
枕头是可用的,不包括原始包几何或纹理.
