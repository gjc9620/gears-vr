# Third-party components

The downloadable release includes CPython 3.12 (with its license), the OpenXR loader,
pefile, and code using MinHook. Their notices are included in the release ZIP.

Source builds require MinHook 1.3.3, OpenXR headers/loader 1.1.63, and pefile 2024.8.26.
These third-party sources and binary SDKs are not vendored in this repository.
Obtain them from their upstream projects and retain their license files.
The launcher artwork was supplied for this project and is included as a project asset.
